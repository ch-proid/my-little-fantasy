# 장비 데이터 (데이터/장비.json)

2026-10-01 만듦. 장비는 모두 `데이터/장비.json` 한 파일로 관리한다. 게임을 켤 때 읽으므로, 고친 뒤 게임을 다시 켜면 바뀐다.

**브라우저(Edge)로 게임을 할 때:** 브라우저는 로컬 json을 못 읽어서 복사본 `데이터/장비.js`를 쓴다. json을 고친 뒤 `python 도구/에셋변환/장비넣기.py`를 한 번 돌리면 된다. `게임 실행.cmd`로 켜면 복사본이 저절로 새로 만들어진다.

## 규칙 (사용자 결정)
- 장비 = 지역 한 벌(8세트)의 한 부위다. 부위는 무기 3종(검·엽총·완드), 방어구 5종(머리·몸통·팔·다리·신발), 장신구 2종(반지·목걸이)이다.
- 같은 지역 장비는 일반부터 판타지아까지 **그림이 같다**. 등급은 능력치와 이펙트만 바꾼다.
- 이름 = 등급 앞말 + 지역 장비 이름이다.
  - 앞말: 일반적인 / 희귀한 / 유니크 / 전설의 / 판타지아
  - 예: "일반적인 들판 목검", "희귀한 숲지기 벌목검", "판타지아 용이빨 검"
- 판타지아 무기는 그 지역 스킬을 쓴다. 지역마다 1개씩, 모두 8개다. 검·엽총·완드가 같은 스킬을 쓰고, 주인공 동작만 무기에 맞춘다(휘두르기 ↔ 쏘기 ↔ 주문).
- 그림은 `에셋/장비/<folder>/`의 PNG다.
  - 방어구는 `주인공.py 넣기`로 게임 코드(art.js HERO_PARTS.gear)에 들어간다.
  - 무기는 게임이 PNG를 바로 읽는다.
  - 반지·목걸이는 그림이 없다(아이콘만).

## 파일 구성
- `grades`: 등급 5개
  - name, prefix(이름 앞말), color, mul(능력치 배율), lines(추가 옵션 수)
  - drop / bossDrop(떨어질 비중), dismantle(분해 골드)
  - fx(공격 이펙트 크기 배율), aura: 무기 빛. 0 없음, 1 반짝이, 2 빛번짐, 3 판타지아
- `stats`: 능력치 공식. 값 = (기본 + 아이템 레벨 × 레벨당) × 등급 배율이고, 아이템 레벨 = 떨어진 스테이지다.
  - weaponAtk, armorHp, armorDef, armorWeight(부위 비중)
  - accessory(반지·목걸이에서 2개 뽑음), lineGrow(등급마다 추가 옵션이 커지는 정도)
- `regions`: 지역 8개
  - set(세트 이름), folder(그림 폴더), color(무기 이펙트 색)
  - fantasia { skill, name }, items(부위마다 이름)

## 게임 안 모습
- 입은 방어구는 주인공 그림에 겹친다. 무기는 손에 쥐고 90도 단위로 휘두른다. 규칙은 장비 미리보기·공격 그림과 같다(`코드/그림/gear.js`).
- 엽총은 늘 두 손으로 든다(서기·걷기·숨쉬기·스킬).
- 옛 저장:
  - 옛 무기 디자인은 그 무기가 나오던 지역 장비로 옮긴다(판타지아는 REGIONS.fanta로 찾는다).
  - 지역을 모르는 장비는 아이템 레벨(스테이지)로 지역을 정한다.
