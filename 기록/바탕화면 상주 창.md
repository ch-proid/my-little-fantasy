# 작업 표시줄 띠 모드 (TBH 같은 방식)

2026-09-29 정함. 본보기: TBH: Task Bar Hero.

## 모양
- 작업 표시줄 바로 위 가운데에 480×110 작은 투명 띠로 뜬다. 하늘·언덕·구름·물은 없고, 땅과 지역 소품(나무, 버섯, 갈대, 소나무, 바위 기둥)만 그린다. 소품은 불투명도 0.6으로 살짝 비치게 한다.
- 글자는 금화, 단계 번호(1-1), 떠오르는 피해 숫자만 남긴다. 알림 글과 "초당 피해"는 뺐다.
- 강화는 오른쪽 위 "강화" 단추를 눌러 여는 메뉴로 뺐다. 살 수 있으면 단추에 빨간 점이 뜬다.
- 반복 사냥 중에는 "도전" 단추가 "강화" 옆에 뜬다.
- **늘 떠 있되 다른 창들보다 아래에 깔린다** (바탕화면 위젯처럼). 게임을 눌러도 곧바로 맨 아래로 돌아간다.
- 바탕화면 보기(`Win+D`)에도 보이게 했다. Win+D는 두 가지로 돈다: ① 창을 모두 내림 → 내려가면 바로 다시 띄움 ② 바탕화면을 맨 위로 올림 → 앞 창이 바탕화면(`Progman`, `WorkerW`)이거나 없으면(0) 게임을 그 위로 올림(활성 창은 안 됨). 0.3초마다 확인.
- 작업 표시줄에 아이콘이 없다. 끌 때는 메뉴(가방 아이콘)의 **종료** 단추. (`Alt+F4`도 된다)
- 메뉴를 열면 창이 위로 330px 늘어나고 앞으로 나온다. 닫으면 띠로 돌아가 다시 맨 아래 층으로. 처음 켤 때 자동으로 열리는 닉네임 창은 앞으로 끌어오지 않는다.

## 파일
- `게임 실행.cmd`: 두 번 누르면 켜진다.
- `코드/창/main.js`: 창을 만들고 맨 아래 층에 두며, 바탕화면이 앞으로 오면 올린다. 메뉴 열기(창 늘리기)·종료를 받는다.
- `코드/창/preload.js`: 게임 화면 → 창 다리 (`window.bar.menu`, `window.bar.quit`).
- `코드/게임/`: 게임 코드. 자세한 구성은 작업 목록 문서 0장. `ZOOM`으로 크기를 바꾼다.
- `마리판.html`: 주소 뒤에 `?bar`가 붙으면 띠 모드, 없으면 원래 480×270 화면.
- `node_modules/`: Electron(창 틀)과 koffi(창 순서를 바꾸고 앞 창을 알아보는 윈도우 기능을 부르는 도구).

## 알아 둘 것
- 저장은 Electron 쪽에 따로 남는다. 브라우저로 하던 저장과 이어지지 않는다.
- 버린 방식: "바탕화면이 앞일 때만 보이기"(앞 창 종류를 0.3초마다 확인). 다른 창을 누르면 사라져서 맨 아래 층 방식으로 바꿨다.
- 선명도: 캔버스를 윈도우 화면 배율(`devicePixelRatio`, 이 PC는 150%)만큼 촘촘히 그린다(`fit` 함수). 전에는 1배로 그린 걸 늘려서 글자가 번졌다.
- 고친 버그: 첫 프레임에서 흐른 시간이 음수가 되면 걷기 그림 번호가 음수가 되어 게임이 멈췄다. 흐른 시간을 0 아래로 못 가게 막았다(`frame` 함수).
- 처음에 해 본 방식(엣지 앱 창, 화면 폭 전체 띠 + 빈 곳 클릭 통과)은 버렸다.
- 컴퓨터를 켤 때 자동으로 띄우려면: `Win+R` → `shell:startup` → `게임 실행.cmd` 바로가기를 넣는다.
