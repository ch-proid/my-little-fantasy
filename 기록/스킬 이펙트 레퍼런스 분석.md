# 스킬 이펙트 레퍼런스 분석

2026-09-29. 자료: `레퍼런스/[메이플 테썹] 3번째 6차 스킬 이펙트 모아보기.mp4` (15분, 1280×720).
5초 간격 모음 그림 전체와, 스킬 셋(암살: 멸 2:48, 마하 엘리시드 9:08, 버티컬 피니셔 9:33)을 0.125~0.25초 간격으로 쪼개 봤다.

## 메이플 6차 스킬이 화려해 보이는 까닭

1. **크기.** 이펙트가 캐릭터보다 몇 배 크다. 화면 절반 이상을 덮는다.
2. **세 겹 색.** 바깥은 검은 먹·연기(대비), 가운데는 진한 원색, 속은 하얀 심지(빛). 여기에 더하기 합성 빛번짐을 얹는다.
3. **칼자국 모양.** 가운데가 굵고 양끝이 뾰족한 초승달. 여러 개가 다른 각도로 겹쳐 X자·소용돌이를 만든다. 앞머리 끝에 하얀 섬광이 터진다.
4. **리듬.** 한 번에 끝나지 않는다. 0.12~0.4초 간격으로 여러 번 친다. 칠 때마다 섬광, 방사선, 불똥.
5. **흐름.** 준비(마법진·어두워짐·모으기) → 터짐(1~2프레임 흰 번쩍임 + 큰 모양) → 이어짐(겹치는 궤적, 연타) → 흩어짐(연기·먹·가루로 0.3~0.5초에 사라짐).
6. **화면 연출.** 화면 전체를 어둡게 하거나 한 색으로 물들인다. 흔들림. 가장자리 색 테두리.
7. **거대 소환.** 반투명한 큰 존재(사신·용·불꽃 하트)가 캐릭터 뒤에 나타난다.
8. **결.** 불은 불꽃 혀, 물은 물보라, 어둠은 먹 튀김처럼 가장자리에 결이 있다.

## 우리 게임에 옮기는 법 (띠 화면 480×110)

- 버퍼를 2배(960×220)로 올려 이펙트를 더 촘촘히 그린다. 캐릭터는 픽셀 그림 그대로.
- 공용 도구: 굵기가 변하는 칼자국(3겹 + 섬광 + 흩어지는 연기), 섬광, 방사선, 연기, 불똥, 파편, 마법진, 화면 어둡게, 번쩍임, 흔들림.
- 판타지아 스킬은 모두 준비 → 터짐 → 이어짐 → 흩어짐 순서를 지킨다. 길이 약 2~2.5초.
- 무기 그림은 벡터로 모양을 그린 뒤 픽셀로 바꾸는 방식("벼리기")으로 만든다. 각도마다 새로 벼려서 휘두르는 동작도 깨지지 않는다. 테두리·명암은 자동.
