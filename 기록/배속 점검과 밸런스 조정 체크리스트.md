**표본 집계:** 평균·중앙값·최솟값/최댓값·표본 수를 함께 기록한다. 대기·도달 시간은 느린 쪽 90백분위(P90), 수익·유효 드롭 수는 적은 쪽 10백분위(P10)도 본다. 시간 안에 목표에 도달하지 못한 표본은 ‘미도달’로 남기고 평균에서 조용히 빼지 않는다.

**비교 단위:** 처치 시간과 재사용 대기시간은 게임 시간 기준, 현실 화면 체감은 ×1 기준. 수익은 전투·걷기·타격 멈춤·사망을 포함한 진행 시간 기준도 함께 계산한다.

- [ ] **역할 차이:** 무리·탱커·원거리·돌격이 체력·피해·속도·거리로 서로 다른 압박을 주는가? 역할 하나만 섞여도 난도가 급등하지 않는가?
- [ ] **혼합 무리:** 2~6마리의 역할 비율·서 있는 순서·겹침이 통과/전멸을 과도하게 결정하지 않는가? 근접과 원거리 모두 자기 공격을 할 수 있는가?
- [ ] **생존:** 일반 피해·적 방어·기절·출혈·밀치기·전투 회복·처치 회복을 함께 본다. 무한 기절·무피해 사냥·죽음 반복이 생기지 않는가?

- [ ] **보스 실패:** 체력 부족·명중 부족·피해 부족·시간 부족을 구분한다. 실패 후 성장으로 통과할 수 있는가? 반복 사냥·재도전 전환이 정확한가?
- [ ] **보상:** 처치한 적만 한 번 보상하는가? 보스 사망 시 흩어진 부하·같은 프레임의 처치·지속 피해·남은 투사체에서 중복/다음 지역 보상이 없는가?
- [ ] **후반 수치:** 체력·방어·피해의 성장률과 플레이어 성장을 비교한다. 매 단계의 예상 장비·레벨에서 일반 처치 시간과 보스 성공률이 목표 범위인가?

### 지역·진행·반복 사냥

- [ ] **경계 난도:** 새 지역 첫 단계가 직전 마지막 단계보다 얼마나 어려운가? 이전 지역 장비로 첫 드롭을 얻을 수 있는가? 특정 지역만 과도한 벽이 되는가?

- [ ] **파밍 선택:** 안전한 이전 단계·현재 단계·보스 중 피해와 사망을 반영한 골드·경험치·유효 장비 효율을 비교한다. 사냥터 선택의 이유가 있는가?
- [ ] **진행 잠금:** 최고 단계·이동·자동 도전·보스 직접 도전·실패 전환·재접속에서 단계가 건너뛰거나 잠금이 풀리지 않는가?
- [ ] **지역 개성:** 몬스터·장비·색·지형·스킬이 바뀌는 것을 작은 화면에서도 느끼는가? 소품은 전투 판정·정보를 가리지 않는가?
- [ ] **80단계 이후:** 성장과 파밍 목표가 이어지는가? 무한 난도·메뉴 선택·수치 표기·저장·반복 사냥이 일관되는가?

### 장비 드롭·가방·분해

- [ ] **확률 분모:** 몬스터당 장비 드롭 → 등급 추첨 → 부위/무기 추첨 → 장착 개선을 따로 기록한다. ‘판타지아 비중’을 처치당 무기 확률로 쓰지 않는다.
- [ ] **추첨 확인:** 일반/보스별 등급·부위·무기 분포가 설정과 맞는가? 추첨 등급과 최종 등급을 구분한다(현재 판타지아 비무기의 일부는 레전더리로 낮아짐). 독립 추첨 시험과 실제 전투 획득 속도를 모두 본다.
- [ ] **희귀 표본:** 중요한 희귀 사건은 충분한 횟수 또는 95% 신뢰구간으로 판단한다. 0회 관찰을 0%로 확정하지 않는다. 첫 획득의 P90·미획득 비율도 기록한다.
- [ ] **유효 드롭:** 첫 장비·첫 방어구·첫 교체·첫 고등급·첫 판타지아·원하는 무기까지 걸리는 시간이 적절한가? 등급은 좋아도 옵션·부위가 맞지 않아 성장이 막히지 않는가?
- [ ] **세트 교체:** 새 지역 장비가 점진적으로 바뀌는가? 이전 고등급과 새 저등급의 선택이 의미 있는가? 반지 2칸·목걸이까지 자연스럽게 채워지는가?
- [ ] **가방 포화:** 장착 장비 포함 여부·60칸 표시·초과 알림·자동 분해·잠금이 일치하는가? 5분/1시간/8시간 방치 뒤 희귀 손실과 정리 노동이 과하지 않은가?
- [ ] **분해 가치:** 판매 골드가 전투 수익을 과도하게 앞서거나 너무 적어 정리가 낭비되지 않는가? 장비 레벨·등급·골드 보너스 적용 규칙이 일관되는가?
- [ ] **옵션 품질:** 같은 옵션 반복·무효 옵션·상한 초과·지나친 편차를 확인한다. 높은 등급의 기본 성능과 스킬 가치가 획득 난도에 맞는가?

참고 기준값: 현재 판타지아 무기는 일반 처치당 약 **0.004%**, 보스 한 번에 하나 이상 약 **0.887%**다. 수정 후 실제 설정으로 다시 계산한다. 생성 시험은 확률을 검증하고, 획득 시간은 실제 처치·재도전 속도로 계산한다.

### 레벨업·경험치

- [ ] **성장 속도:** 첫 레벨·레벨별 대기·지역 진입 레벨을 기록한다. 초기 성장을 바로 느끼고 후반 대기가 목표 범위를 넘지 않는가?

- [ ] **정산:** 다중 레벨업·보스 처치·방치·경험치 옵션·가져오기에서 경험치/점수 누락·중복·음수·표시 오차가 없는가?

- [ ] **첫 구매:** 첫 강화까지 걸리는 시간과 실제 피해·생존 개선이 체감되는가? 빈 슬롯 강화·다른 장비로 교체 시 효과와 비용이 유지되는가?

- [ ] **투자 가치:** 레벨업과 재추첨 비용을 강화·장비 교체와 비교한다. 초반부터 유일한 최적 소비처가 되거나 후반에도 버려지지 않는가?

- [ ] **파밍 경제:** 가장 좋은 골드 사냥터가 경험치·장비 사냥터까지 항상 독점하지 않는가? 이전 보스만 반복하는 방식이 모든 진행을 앞서지 않는가?
- [ ] **숫자 처리:** 비용·잔액·분해·만/억/조 표기·소수·큰 수가 실제 값과 맞는가? 재접속·빠른 클릭·후보 선택에서 비용 중복/누락이 없는가?

### 방치·저장·실행 안정성

- [ ] **실측 비교:** 같은 캐릭터·사냥터의 온라인 반복 사냥 수입과 오프라인 보상을 비교한다. 효율 50%의 기준과 무기별 오차를 명시한다.
- [ ] **위험한 단계:** 죽음이 반복되는 현재 단계에서 방치 보상이 안정 사냥처럼 과하게 나오지 않는가? 직전 안전한 단계보다 위험한 단계가 무조건 이득인가?

- [ ] **창:** 확인 가능한 환경에서 Win+D·메뉴 확장·포커스·화면 배율·작업 표시줄 배치·종료를 본다. 숨긴 시험으로 확인한 범위와 실제 창 시험 범위를 구분한다.

## 7. 조정 루프

**매회:** 초기 상태 고정 → 측정 → 원인 설명 → 수치 한 묶음 조정 → 같은 씨앗으로 재시험 → 다른 씨앗으로 확인 → ×1 체감 확인 → 결과 기록.

| 회차 | 집중할 일 | 다음 회차로 넘어갈 조건 |
|---|---|---|
| 1. 기준 측정 | 알려진 오류, 시간·보상·저장 신뢰성, 자연 진행 기준값 | 중복/누락과 진행 중단 원인을 구분했고 비교 가능한 기록이 있음 |
| 2. 전투·지역 | 무기·역할·보스, 지역 경계와 후반 성장 곡선 | 정한 성장 조건에서 전 지역 통과 경로가 있고 무기별 불합리한 벽이 줄어듦 |
| 3. 성장·경제 | 레벨·강화·어빌리티·골드, 소비 전략 | 성장 선택으로 정체를 풀며 수입과 비용이 목표 대기시간에 맞음 |
| 4. 파밍·방치 | 유효 드롭·희귀 운·가방·반복 사냥·재접속 | 획득 중앙값/P90과 방치 수익이 목표 범위, 희귀 손실·중복 없음 |
| 5. 체감·회귀 | ×1 UX/UI, 환경 차이, 최악의 운, 장시간 누적 | 수치 개선이 실제 화면에서도 느껴지고 기존 기능을 망가뜨리지 않음 |

필요한 회차는 반복한다. 한 번에 서로 다른 원인의 수치를 모두 바꾸지 않는다. 전투가 빨라지면 골드·경험치·드롭도 같이 늘어나므로, 관련 결과를 반드시 다시 본다.

**수정 후 최소 재검사:** 무기 3종의 새 게임·첫 보스 → 영향받은 지역과 직전/다음 경계 → 후반 보스 → 가방/골드/경험치 → 저장 재로딩·방치 → ×1 관련 화면. 전투·성장 공식을 바꾸면 전체 진행도 다시 비교한다.

**판정:** 치명적인 진행·저장·보상 오류는 0건. 주요 시간·성공률·수익은 정한 목표 범위. 특정 무기·소비 전략의 차이는 플레이 역할로 설명 가능. 미확인 항목은 통과 처리하지 않는다.

## 8. 회차별 기록 양식

```md
### 회차 N / 커밋 또는 수정안 / 날짜
- 조건: 환경, 배속·시간 방식, 씨앗 수, 초기 저장, 행동·소비 규칙
- 목표: 도달/처치/획득/성장 대기/개입 간격의 목표 범위
- 결과: 중앙값·P90·미도달/실패율·수익·지출·희귀 손실·체감
- 문제: 재현 조건 → 관찰값 → 원인 → 영향 범위
- 변경: 파일·항목, 이전 값 → 새 값, 변경 이유
- 전후: 같은 조건의 개선량, 다른 씨앗에서도 유지되는지
- 재검사: 통과/실패/미확인, 부작용과 되돌릴 조건
- 다음: 남은 가장 큰 문제 1~3개
```

최종 보고에는 **최종 수치·변경 이유·목표 대비 결과·남은 문제·검증 범위**를 남긴다. 시험 저장과 결과를 보존하고, 수정한 파일과 현재 장비 JSON/JS의 일치를 확인한다.
