# 지역 컨셉 프롬프트

2026-09-30 작성. 사용자가 이 프롬프트로 GPT에서 컨셉 그림을 뽑아 오면, 모양과 색만 따서 우리 그림체(글자 지도, 2px 칸)로 다시 찍는다. 1지역(숲 묶음)과 6지역(얼음 묶음)은 먼저 만들었다. 6지역 프롬프트는 2026-10-01에 더했다.

## 쓰는 법
[공통]과 [지역] 하나를 이어 붙여 한 번에 넣는다. 한 장에 몬스터 5마리(일반 4 + 보스 1)가 나온다.

## [공통] — 앞의 컨셉 작업에서 배운 것
- 배경 한 색: 누끼를 딸 때 배경과 몬스터가 섞이지 않게 한다.
- 서로 띄우기: 붙어 있으면 한 덩어리로 잘린다.
- 발밑 그림자·풀·눈 없음: 이게 있으면 발에 부스러기가 붙는다.
- 모두 왼쪽 보기: 몬스터는 왼쪽의 용사에게 걸어온다.
- 단순한 모양: AI 그림이 복잡해서 튀었다.

```
귀여운 2D 도트 게임 몬스터 컨셉 시트. 한 장에 몬스터 5마리를 가로 한 줄로, 서로 넉넉히 떨어뜨려 그린다.
모두 몸을 왼쪽으로 향한 옆모습에 가까운 3/4 시점. 큰 머리와 작은 팔다리의 통통한 꼬마 비율, 큰 눈.
모양은 아주 단순하게: 큰 덩어리 몇 개로 된 또렷한 실루엣, 잔무늬·털 한 올·작은 장식은 넣지 않는다.
굵고 어두운 테두리, 색마다 명암은 3~4단계, 몸 전체 색은 6~8가지 이내.
배경은 무늬 없는 한 가지 색(연회색 #d8d8d8). 발밑 그림자, 땅, 풀, 눈, 글자, 테두리 상자는 넣지 않는다.
크기로 강함을 보인다: 약한 무리는 작게, 탱커는 크고 넓게, 보스는 가장 크고 화려하게(다른 몬스터의 1.5배).
```

## [지역 2] 이끼 숲
주의: 1지역이 이미 새싹·도토리·버섯·그루터기·부엉이라서 겹치지 않게 "나무꾼 마을" 쪽으로 틀었다.
```
지역: 이끼 숲. 나무꾼 마을을 숲이 삼켜 버렸다. 이끼, 녹슨 쇠, 빛나는 포자 색(짙은 초록, 갈색, 청록 빛).
1) 포자 반딧불이(작음, 원거리): 엉덩이에 빛나는 청록 포자 주머니를 단 통통한 벌레, 떠다님.
2) 이끼 통나무 애벌레(작음, 무리): 이끼 덮인 통나무 토막 여러 개가 이어진 애벌레.
3) 녹슨 톱 게(보통, 돌격): 등딱지 대신 녹슨 둥근 톱날을 짊어진 게.
4) 이끼곰(큼, 탱커): 등에 이끼와 작은 버섯이 자란 큰 곰, 한쪽 어깨에 부러진 도끼자루.
5) 보스 - 분노한 고목: 줄기에 도끼 자국과 도끼가 박힌 거대한 나무, 성난 눈, 뿌리 다리, 이끼 수염.
```

## [지역 3] 고블린 고개
```
지역: 고블린 고개. 고블린 족장이 조각에 "모든 걸 갖고 싶다"고 빌었다. 가죽, 나무, 훔친 금붙이(연두 피부, 갈색 가죽, 금색).
1) 고블린 약탈꾼(작음, 무리): 훔친 자루를 멘 작은 고블린, 짧은 단검.
2) 전투 멧돼지(보통, 돌격): 몸을 앞으로 숙인 멧돼지, 등에 약탈품 자루, 큰 엄니.
3) 고블린 주술사(보통, 원거리): 해골 달린 지팡이, 깃털 머리장식, 초록 불꽃.
4) 오우거(큼, 탱커): 배 나온 큰 오우거, 통나무 몽둥이, 훔친 냄비를 투구로 씀.
5) 보스 - 고블린 족장: 멧돼지를 탄 고블린, 크기가 안 맞는 훔친 왕관, 붉은 망토, 큰 도끼.
```

## [지역 4] 잠긴 호수 마을
```
지역: 잠긴 호수 마을. 비가 그치지 않아 마을이 물에 잠겼다. 물, 해초, 꺼지지 않는 등불(푸른 청록, 흰 물빛, 따뜻한 등불 노랑).
1) 등불 해파리(작음, 원거리): 머리 안에 작은 등불이 켜진 해파리, 떠다님.
2) 개구리 기사(작음, 무리): 냄비 뚜껑 방패와 포크 창을 든 개구리.
3) 집게게(보통, 탱커): 한쪽 집게가 아주 큰 빨간 게, 등에 조개와 해초.
4) 익사한 등불 유령(보통, 원거리): 해초가 걸친 반투명 유령이 옛 가로등 등불을 든다, 떠다님.
5) 보스 - 종을 쓴 대왕문어: 종탑의 커다란 종을 모자처럼 쓴 문어, 다리에 해초, 금빛 종.
```

## [지역 5] 태양 사막 신전
```
지역: 태양 사막 신전. 해가 멈춰 호수가 말라 사막이 되었다. 모래, 흙, 금빛 태양 문양(모래 노랑, 테라코타, 금, 청록 보석).
1) 햇살 정령(작음, 무리): 작은 태양 모양 불꽃 정령, 떠다님.
2) 전갈(보통, 돌격): 몸을 낮춘 주황 전갈, 꼬리 끝에 빛나는 침.
3) 모래 뱀(보통, 원거리): 모래에서 몸을 세운 뱀, 머리에 태양 문양 장식.
4) 흙 병사(큼, 탱커): 태양 문양 방패와 깃털 투구를 쓴 테라코타 흙인형 병사.
5) 보스 - 태양 석상 골렘: 부서진 태양신 석상 머리가 몸통인 돌 골렘, 가슴에 빛나는 청록 보석.
```

## [지역 6] 얼어붙은 축제 산
주의: 이 지역은 몬스터가 6마리(일반 5 + 보스)다. [공통]의 "5마리"를 "6마리"로 바꿔 넣는다. 게임에 이미 있는 이름(id)에 맞췄다: iceSlime, crystalBeetle, frostOwl, frostYeti, iglooMimic, 보스 snowKing.
```
지역: 얼어붙은 축제 산. "이 축제가 영원히 끝나지 않게 해 주세요"라는 소원 때문에 겨울 축제의 밤이 끝나지 않고, 모든 것이 축제 차림 그대로 얼어붙었다. 흰 눈, 연하늘 얼음, 축제 빨강, 금빛 등불(흰색, 연하늘, 빨강, 금색).
1) 얼음 방울(작음, 무리): 동그란 얼음 젤리, 머리에 작은 빨간 털방울 모자.
2) 수정 딱정벌레(보통, 돌격): 등딱지가 연하늘 얼음 수정 조각으로 된 딱정벌레, 몸을 낮추고 달려든다.
3) 서리 부엉이(보통, 원거리): 흰 깃털 부엉이, 목에 빨간 목도리, 날개 끝이 얼음, 떠다님.
4) 서리 설인(큼, 탱커): 털이 복슬복슬한 흰 설인, 축제 빨간 목도리와 작은 금방울.
5) 이글루 흉내쟁이(큼, 탱커): 입구가 이빨 난 입이 된 작은 이글루, 문 위에 축제 등불 한 줄.
6) 보스 - 모자 쓴 눈사람 왕: 커다란 눈사람, 큰 빨간 왕관 모양 털모자, 당근 코, 나뭇가지 팔에 얼음 홀, 목에 금방울 목도리.
```

## [지역 7] 그림자 폐성
```
지역: 그림자 폐성. 영원한 밤을 빈 왕국 사람들이 그림자가 되었다. 어둠, 찢어진 천, 빛나는 눈(짙은 보라, 검정, 연보라 빛, 녹슨 은색).
1) 그림자 박쥐(작음, 무리): 빛나는 두 눈만 보이는 둥근 그림자 박쥐, 떠다님.
2) 그림자 사냥개(보통, 돌격): 몸을 앞으로 숙인 그림자 개, 끊어진 목줄.
3) 그림자 망령(보통, 원거리): 찢어진 망토 모양 유령, 손에 보라 불꽃, 떠다님.
4) 빈 갑옷 기사(큼, 탱커): 속이 빈 갑옷, 투구 틈으로 연보라 빛, 찢어진 문장 방패.
5) 보스 - 그림자 기사왕: 금이 간 왕관을 쓴 거대한 그림자 기사, 찢어진 망토, 큰 검.
```

## [지역 8] 용의 둥지
```
지역: 용의 둥지. 늙은 용 아우룸이 쓰러진 곳, 가장 큰 수정 조각이 빛난다. 용암, 수정, 금빛 비늘(주황 용암, 보라 수정, 금색).
1) 아기 용(작음, 돌격): 등에 작은 보라 수정이 박힌 주황 아기 용.
2) 수정 정령(보통, 원거리): 떠다니는 보라 수정 덩어리에 눈이 달림.
3) 타락한 별 기사(보통, 돌격): 부서진 별 조각 갑옷의 기사, 보라 빛 창.
4) 용암 골렘(큼, 탱커): 검은 바위 몸 틈으로 용암이 흐르는 골렘.
5) 보스 - 고룡 아우룸의 그림자: 금빛 비늘의 거대한 늙은 용의 반투명한 그림자, 가슴에 빛나는 수정.
```
