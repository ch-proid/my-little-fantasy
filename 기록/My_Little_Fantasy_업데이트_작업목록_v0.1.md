작성일: 2026-09-29 · 개발자 인계용 · 파일 이름은 v0.1 그대로 둔다

> **v0.3 (2026-09-29):** 유니크·레전더리는 스킬 없음, 외형만 화려. 기존 유니크 스킬 3종은 판타지아 네임드 무기로 옮김(판타지아 종류마다 6종, 모두 18종). 이펙트는 메이플 6차 스킬 영상을 분석해 새로 만듦. 무기는 등급마다 실루엣이 달라짐.
>
> **v0.2 추가 결정 (2026-09-29):** 일반 등급은 흰색. 방어구·장신구도 같은 줄 수 규칙. 무기 하나에 스킬 1개. 유니크 스킬은 3종(무기 종류마다 1개). 판타지아는 네임드 무기로 종류마다 5종 이상. 시안은 `도구/무기 미리보기.html`.
>
> **v0.2 변경 (2026-09-29):** 4직업 시스템을 없애고 **무기 3종(검·엽총·완드)** 으로 바꾼다. 공격 방식은 직업이 아니라 장착한 무기가 정한다. 장비에 **5등급(일반·레어·유니크·레전더리·판타지아)** 을 두고, 레어부터 추가 능력치가 1줄씩 늘며, 유니크부터 무기에 스킬 같은 화려한 추가 공격이 붙는다. 바뀐 곳: 2·3장, SYS-01·03, 6장 전체(JOB-01 → WEAPON-01~02), ITEM-01~02, ABILITY-01 표, LOOK-01, UI-01, BAL-01, QA-01, 12·13장.

이 문서는 현재 단일 HTML 프로토타입을 무기·스탯·장비 파밍 중심의 클래식 방치형 RPG로 확장하기 위한 작업 목록이다. 코드 변경 완료 보고서가 아니다. 모든 체크박스는 앞으로 구현하거나 확인할 작업이다.

## 0. 구현 현황 (v0.4, 2026-09-29)

게임을 여러 파일로 나눠 새로 짰다. 옛 한 파일짜리 게임은 `이전 버전/my little fantasy v1.html`에 남겼다.

| 파일 | 하는 일 |
|---|---|
| `마리판.html` | 껍데기: 메뉴 패널 + 띠 캔버스 + 스타일 |
| `코드/게임/data.js` | 밸런스, 손맛 연출 수치(JUICE), 등급, 장비, 지역 8개, 몬스터 역할, 외형 |
| `코드/게임/monsters.js` | 몬스터 40종 (벼리기) |
| `코드/게임/props.js` | 지역 소품 32종(이야기 단서), 방어구·장신구 아이콘(등급별 모양) |
| `코드/게임/state.js` | 저장(서명·백업·옛 저장 변환·내보내기/가져오기), 능력치 계산, 장비·강화, 어빌리티, 외형, 방치 보상 |
| `코드/게임/combat.js` | 무리 전투, 무기 3종 공격, 몬스터 역할, 상태 이상, 보상·드롭, 스테이지, 판타지아 스킬 |
| `코드/게임/render.js` | 지역·몬스터·용사·이펙트·메인 화면 아이콘 |
| `코드/게임/ui.js` | 메뉴 6탭 + 종료, 닉네임 창, 알림 |
| `코드/게임/main.js` | 시작·돌리기·입력 |
| `코드/그림/`, `코드/스킬/` | 무기 미리보기와 공유: 픽셀 그림, 이펙트, 무기 벼리기, 판타지아 스킬 18종 |

**메인 화면:** 금화 아이콘+숫자, `1-1` + 모드 아이콘(자동 도전 ⏩ / 반복 사냥 ↻, 누르면 바뀜), 가방 아이콘(메뉴, 새 소식이면 빨간 점). 용사 머리 위 레벨, 발밑 닉네임.

**구현하며 정한 기본값 (임시, 바꿀 수 있음):**
- 스테이지: 지역당 10단계, 10마리 잡으면 보스(30초). 무리 수 = 2 + (스테이지-1)/4, 최대 6.
- 회복: 한동안 안 맞으면 초당 10%, 전투 중 초당 0.4%, 처치마다 4%.
- 명중 = 82% + (명중-회피)/160 (50~100%). 받는 피해 = 피해 × 100/(100+방어×3).
- 강화: 칸 강화(장비를 바꿔도 칸에 남음), 항상 성공, 단계당 기본 옵션 +6%, 최대 30.
- 드롭: 일반 몬스터 9%, 보스 2개. 판타지아 무기는 지역별 목록에서(세계관 문서). 가방 60칸, 가득 차면 골드로 바꾸고 알린다.
- 어빌리티: 1·10·20레벨에 칸. 뽑은 결과는 바로 저장(다시 켜서 공짜로 바꾸기 불가). 같은 옵션은 두 칸에 없음.
- 옛 저장(1판): 골드 강화에 쓴 골드를 전부 돌려준다. 스테이지·최고 스테이지·반복 사냥 여부 유지. 1판 저장은 지우지 않는다.
- 방치 보상: 골드·경험치 50%, 최대 8시간, 장비는 없음. 30초 넘게 멈췄다 돌아와도 방치 보상으로 정산.
- 스킬: 판타지아 무기를 끼면 14초마다 저절로.
- 창: 메뉴를 열면 창이 위로 늘어난다. 사용자가 열 때만 앞으로 나온다(자동으로 열릴 땐 다른 프로그램을 가로채지 않음).

**아직 안 한 것:** 보스 고유 행동(지금은 크고 센 몬스터), 몬스터 역할별 특수 패턴 세분화, 사운드, 외형은 머리·옷 색만.

## 1. 적용 기준

- **확정 방향:** 사용자가 직접 제시한 내용과 직전 답변에서 채택한 권장안.
- **초기 시험값:** 3~6마리 무리, 어빌리티 1→3슬롯처럼 먼저 시험할 규모. 최종 밸런스 수치가 아니다.
- **구현 제안:** 기능을 구현하기 위한 구조와 예외 처리 제안. 새로운 콘텐츠 확정과 구분한다.
- **미정:** 공식·수치·정책을 추가로 정해야 하는 항목. 임의로 확정하지 않는다.

검토한 자료는 `마리판.html` 826줄, `바탕화면 상주 창.md`, 첨부 화면 이미지다. `main.js`, 실행 스크립트, HTML 주석에서 언급한 `sim.js`는 제공되지 않았다. 창 제어 기능은 MD의 기존 요구사항을 기준으로 하며 실제 Windows 동작 확인이 필요하다.

기존 MD는 바탕화면 창 동작 기록으로 유지한다. 본 문서가 게임 시스템 변경 작업을 담당한다.

- [ ] 최소값이 최대값을 넘는 경우, 명중·치확·공속의 상한, 방어력 피해 감소 한계를 정의한다.
- [ ] `% 증가`와 `%p 증가`를 내부 데이터와 UI에서 혼동하지 않도록 옵션별 단위를 지정한다.

완료 기준: UI 표시와 실제 전투가 같은 계산을 사용한다. 체력 장비 해제·재장착이나 재분배를 반복해 무료 회복하는 문제가 없도록 현재 체력 변경 정책을 적용한다. 구체 정책은 미정이다.

## 6. 무기와 전투

직업은 두지 않는다. 주인공은 하나이고, **장착한 무기의 종류가 공격 방식을 정한다.** 무기를 바꾸면 그 자리에서 싸우는 모습이 바뀐다.

### WEAPON-01 · 무기 3종과 기본 공격

| 무기 | 거리 | 기본 공격 | 붙는 효과 |
|---|---|---|---|
| 검 | 근거리 | 앞의 적 최대 3명을 한 번에 벤다 | 경직(맞은 적이 잠깐 멈춤) |
| 엽총 | 원거리 | 1명을 쏜다 | 출혈(시간에 따라 피해), 뒤의 적 1명 관통(피해 감소), 넉백(뒤로 밀림) |
| 완드 | 원거리 | 파이어볼을 던진다 | 떨어진 곳에서 폭발해 주변 여러 적에게 피해 |

- [ ] 무기 종류별 공격 동작과 판정을 구현한다. 모든 무기는 등급과 상관없이 위 기본 공격을 가진다.
- [ ] 사거리, 공격 영역, 최대 타격 수, 준비 시간, 타격 시점, 후딜레이를 무기 종류별 데이터로 둔다.
- [ ] 상태 효과를 공통 구조로 만든다: 경직·출혈·넉백·관통·폭발. 같은 효과가 겹칠 때(출혈 중첩, 경직 연장) 규칙을 데이터로 둔다.
- [ ] 보스에게 경직·넉백이 그대로 걸리면 보스전이 무너진다. 보스는 면역 또는 효과 감소로 둔다.
- [ ] 엽총 넉백으로 적이 밀려나면 근거리로 돌아오는 시간이 생긴다. 원거리 무기라서 문제는 적지만, 검으로 바꾼 직후 밀린 적이 있을 때도 확인한다.
- [ ] 방어구와 장신구는 무기 종류와 상관없이 공용이다.
- [ ] 무기를 바꾸면 공격 동작·사거리가 즉시 바뀐다. 공격 도중 교체 시 진행 중인 공격 처리 규칙을 정한다.
- [ ] 캐릭터 그림에 엽총·완드 들기와 발사 동작, 파이어볼·폭발·출혈 연출을 추가한다. 띠 모드(480×110)에서도 읽히는 크기로 만든다.
- [ ] 세 무기가 모든 상황에서 한 가지만 좋지 않도록 무리 사냥(완드·검 유리)과 단일 보스(엽총 유리)를 따로 비교한다.

완료 기준: 무기를 바꾸면 이름만 바뀌는 것이 아니라 공격 방식이 화면과 전투 결과에 드러난다. 정확한 사거리·대상 수·피해 계수·효과 수치는 밸런스 데이터로 확정한다.

### WEAPON-02 · 무기 스킬과 등급별 외형

**스킬은 판타지아(네임드 무기)에만 있다.** 유니크·레전더리는 스킬 없이 외형만 화려해진다. 무기 하나에 스킬 1개. 일정 시간마다 저절로 나간다.

미리보기: `도구/무기 미리보기.html` (코드는 `코드/그림/`, `코드/스킬/` 폴더). 이펙트 원칙은 `기록/스킬 이펙트 레퍼런스 분석.md` (메이플 6차 스킬 영상 분석).

**등급별 외형.** 등급이 오를수록 무기가 커지고, 장식이 늘고, 실루엣 자체가 바뀐다. 레전더리부터 손에 쥐고 있어도 빛난다.

| 등급 | 검 | 엽총 | 완드 |
|---|---|---|---|
| 일반 | 낡은 검 (짧은 민검) | 낡은 엽총 | 나무 완드 |
| 레어 | 기사의 검 (긴 날, 굽은 가드, 푸른 보석) | 쌍열 엽총 (총열 둘, 띠) | 수정 지팡이 (갈퀴가 수정을 쥠) |
| 유니크 | 검객의 검 (잎 모양 날, 금날개 가드, 술) | 황금 사냥총 (조준경, 금장) | 황금 나선 지팡이 |
| 레전더리 | 검성의 검 (물결 날, 가시 가드, 빛나는 심지) | 진홍 폭풍총 (탄창, 총검) | 진홍 수정관 (수정 셋, 날개) |

**판타지아 — 네임드 무기. 종류마다 6종, 모두 18종 (1차 시안).** 모양도 무기마다 다르다.

| 무기 | 이름 | 스킬 | 흐름 |
|---|---|---|---|
| 검 | 천하무쌍 | 검기 난무 | 금빛 검기 6줄이 X자로 엇갈린 뒤 화면을 가로지르는 거대 검기 |
| 검 | 새벽가르개 | 천공낙검 | 마법진·빛기둥 → 빛의 대검이 꽂힘 → 충격파·기절 → 깃털로 흩어짐 |
| 검 | 벚꽃무희 | 꽃보라 베기 | 벚꽃 회오리 안에서 칼날 연타 → 분홍 X자 검기 → 꽃잎 폭발 |
| 검 | 천둥송곳니 | 뇌광 돌진 | 번개로 꿰뚫는 돌진 → 벼락 넷 → 번개 X자 검기 |
| 검 | 달그림자 | 그림자 분신 | 달이 뜨고 화면이 어두워짐 → 분신 셋과 먹빛 X자 4연타 → 거대 베기 |
| 검 | 화산의 심장 | 분화 | 뛰어올라 내려찍기 → 땅이 갈라지며 불기둥 차례로 → 넷 동시 폭발 |
| 엽총 | 폭풍의 나팔총 | 산탄 폭풍 | 부채꼴 불꽃 산탄 5연발 → 불기둥째 뿜는 마지막 한 발 |
| 엽총 | 별비 사냥꾼 | 유성우 | 하늘로 한 발 → 별 터짐 → 별똥별 비 → 큰 유성 폭발 |
| 엽총 | 붉은 까마귀 | 까마귀 떼 | 까마귀 떼가 할퀴고 지나감 → 거대 까마귀 그림자가 화면을 가름 |
| 엽총 | 뇌명 | 연쇄 번개탄 | 번개가 적에서 적으로 튀며 마법진을 새김 → 벼락 기둥 넷 |
| 엽총 | 방울방울 | 거품 감옥 | 무지개 방울에 가둬 띄움 → 터지며 낙하 → 하늘의 큰 방울 폭발 |
| 엽총 | 은하 관통자 | 은하 레일 | 화면이 우주로 → 별빛 모으기 → 은하 광선 관통 → 끝에서 초신성 |
| 완드 | 용심장 지팡이 | 드래곤 브레스 | 거대 마법진에서 드래곤이 솟아 불길 → 불바다 폭발 |
| 완드 | 불사조 깃털 | 불사조 강림 | 불의 마법진 → 불꽃 날개 불사조가 가로지름 → 불깃털 비 |
| 완드 | 서리여왕의 홀 | 고드름 폭포 | 얼음 마법진·눈보라 → 거대 고드름 → 얼음 가시가 솟았다 깨짐 |
| 완드 | 폭풍의 눈 | 회오리 폭발 | 회오리가 적을 빨아들임 → 터지며 바람 칼날이 사방으로 |
| 완드 | 별자리 지팡이 | 별자리 낙인 | 별자리판이 돌고 별이 이어짐 → 별이 하나씩 낙하 → 큰 별 |
| 완드 | 숲의 노래 | 옛 뿌리 | 뿌리가 솟아 적을 묶음 → 가시 → 거대한 꽃이 피며 꽃잎 폭풍 |

- [ ] 판타지아 스킬은 모두 준비(무대 어둡게·마법진) → 터짐(번쩍임·섬광) → 연타 → 흩어짐(연기·가루) 순서를 지킨다. 길이 약 2~2.5초.
- [ ] 스킬의 발동 주기, 피해 계수, 범위, 연출 길이를 데이터로 둔다. 스킬은 공통 피해 계산 경로를 쓴다.
- [ ] 새 상태 효과를 공통 구조에 넣는다: 빙결, 속박, 감전, 화상, 저주, 띄우기, 끌어당기기, 가둠. 보스 면역 규칙을 함께 정한다.
- [ ] 무기 그림은 "벼리기" 방식으로 만든다: 벡터 모양 → 픽셀 → 자동 테두리·명암. 각도마다 새로 벼려서 휘두르는 동작을 매끄럽게 한다.
- [ ] 스킬 중 화면 어둡게 하기는 띠 창 안에서만 일어난다. 바탕화면 상주 중 너무 번쩍이지 않게 번쩍임 세기를 따로 조절할 수 있게 한다.
- [ ] 다수 적 동시 타격 때 피해 숫자 표시를 줄인다.

미정:
- 공격속도%가 스킬 발동 주기도 줄이는지.
- 판타지아 무기의 기본 공격도 무기마다 조금씩 다른지, 스킬만 다른지.
- 방어구·장신구의 등급별 외형 변화 범위.

완료 기준: 등급이 오르면 무기 모양으로 바로 드러나고, 판타지아 스킬은 준비부터 흩어짐까지 한 편의 연출로 읽힌다. 스킬 발동과 보상이 중복 처리되지 않는다.

## 7. 장비·파밍·강화

| 슬롯 | 수 | 기본 옵션 배치 방향 |
|---|---:|---|
| 무기 | 1 | 공격력 중심 |
| 머리 | 1 | 체력·방어력 중심 |
| 몸통 | 1 | 체력·방어력 중심 |
| 팔 | 1 | 체력·방어력 중심 |
| 다리 | 1 | 체력·방어력 중심 |
| 신발 | 1 | 체력·방어력 중심 |

- [ ] 장비 고유 ID, 부위, 무기 종류(무기만), 등급, 기본 옵션, 추가 능력치, 무기 스킬(유니크 이상 무기만), 잠금 여부를 관리한다.
- [ ] 반지 슬롯 두 개를 구분하고, 같은 아이템 인스턴스를 두 슬롯에 중복 장착하지 못하게 한다.
- [ ] 장착·해제·교체·비교 표시를 구현한다.

완료 기준: 교체 즉시 공통 능력치가 갱신된다. 동일 종류 반지 두 개를 허용할지는 별도 미정이다.

### ITEM-02 · 장비 등급과 추가 능력치

| 등급 | 색 | 추가 능력치 | 무기 스킬 |
|---|---|---:|---|
| 일반 | 흰색 | 0줄 | 없음 |
| 레어 | 파란색 | 1줄 | 없음 |
| 유니크 | 노란색 | 2줄 | 없음 (외형만 화려) |
| 레전더리 | 붉은색 | 3줄 | 없음 (외형 + 손에 쥐면 빛남) |
| 판타지아 | 보라색 | 4줄 | 네임드 무기 고유 스킬 |

추가 능력치 후보 (기존 `희귀 옵션` 목록을 이름만 바꿔 쓴다):

| 옵션 후보 | 정의 |
|---|---|
| 데미지% | 피해량 증가 옵션. 공격력과의 계산 관계는 별도 공식으로 확정 |
| 치명타 확률% | 치명타 발생 확률 |
| 치명타 피해% | 치명타 피해 배율 |
| 힘%·근력%·민첩% | 개별 스탯 증가 |
| 최소 데미지% | 피해 범위 하한 증가 |
| 최대 데미지% | 피해 범위 상한 증가 |

- [ ] 등급 이름·색·추가 능력치 줄 수를 데이터로 둔다. 장비 이름과 테두리에 등급 색을 쓴다.
- [ ] 등급별 추가 능력치 수치 범위를 설정한다. 높은 등급일수록 줄 수만 많은지, 한 줄의 수치도 큰지 정한다.
- [ ] 부위별 등장 가능한 추가 능력치와 확률을 데이터로 관리한다. 한 장비 안에서 같은 능력치 줄이 겹쳐도 되는지 정한다.
- [ ] 등급별 드롭 확률을 정한다. 판타지아는 게임 이름과 이어지는 최상위 등급이니 드롭 순간 연출을 따로 둔다.

확정: 방어구·장신구도 무기와 같은 등급·줄 수 규칙을 따른다. 스킬은 무기에만 붙는다.

미정: 무기 종류에 따라 붙을 수 있는 추가 능력치가 다른지(예: 엽총에만 출혈 피해%).

### ITEM-03 · 드롭과 인벤토리

- [ ] 지역·몬스터·보스별 드롭 테이블을 추가한다.
- [ ] 장비 자동 획득, 목록 정렬·필터·비교를 제공한다.
- [ ] 등급별 자동 분해와 즐겨찾기 잠금을 지원한다. 장착·잠금 장비는 자동 분해에서 보호한다.
- [ ] 가방이 찼을 때 획득 장비를 처리하는 규칙을 정한다. 무통보 삭제를 기본 처리로 두지 않는다.
- [ ] 원하는 장비를 얻기 위해 사냥터를 고를 수 있도록 획득처를 표시한다.

미정: 인벤토리 용량, 드롭 확률, 분해 보상, 저등급 장비 처리, 낮은 지역 고유 장비의 장기 활용 방식. 강화 계승은 장비 자체의 품질 차이를 해결하는 규칙과 구분한다.

### ITEM-04 · 골드 장비 강화

- [ ] 골드로 장비 성능을 강화한다.
- [ ] 장비를 바꿔도 강화 투자가 사라지지 않는 구조를 적용한다.
- [ ] **구현 제안:** 장비 슬롯별 강화 단계를 보관하고 교체 장비에 적용한다. 이전 권장안의 우선안이며, 장비 자체 강화+계승 방식도 대안으로 남아 있었다. 데이터 구조 확정 시 한 방식으로 닫는다.
- [ ] 강화는 이미 가진 옵션의 수치를 정해진 범위에서 높인다. 옵션 종류·등급·무기 스킬의 획득은 파밍이 담당한다. 강화로 등급이나 추가 능력치 줄 수가 오르지는 않는다.
- [ ] 강화 대상 옵션, 상한, 비용, 성공 방식, 최대 단계를 데이터로 정의한다.

완료 기준: 교체 후 강화가 중복 적용되지 않는다. 강화만으로 치확·공속 등 정해진 능력치 상한을 우회하지 않는다.

## 8. 어빌리티

### ABILITY-01 · 레벨·슬롯·옵션 후보

| 구분 | 옵션 |
|---|---|
| 장비 기본 옵션 공통 | 공격력·체력·방어력·명중 |
| 장비 추가 능력치 공통 | 데미지%·치확%·치뎀%·힘%·근력%·민첩%·최소 데미지%·최대 데미지% |
| 어빌리티 추가 | 골드 획득량·경험치 획득량·공격속도% |

- [ ] 골드로 어빌리티 레벨을 올린다.
- [ ] 지정된 레벨에서 어빌리티 슬롯을 해금한다.
- [ ] 초기 시험 범위는 1슬롯 시작, 최대 3슬롯이다. 해금 레벨·최종 상한은 밸런스 확정 시 정한다.
- [ ] 레벨에 따라 옵션 수치 범위와 변경 비용을 높인다.
- [ ] 동일 옵션을 여러 슬롯에 중복 보유하지 못하게 한다. 힘%·근력%·민첩%는 서로 다른 옵션 키다.
- [ ] 레벨업 시 기존 옵션도 같은 품질 기준으로 상승시켜 다시 뽑을 필요가 없게 한다. 품질의 보관·변환 공식은 미정이다.

완료 기준: 슬롯 해금·레벨업·재접속으로 옵션이 소실되거나 중복 생성되지 않는다. 골드·경험치 획득 옵션의 적용 대상과 단위는 별도로 정한다.

### ABILITY-02 · 골드를 사용한 슬롯별 변경

- [ ] 변경할 슬롯 하나를 고르고 골드를 지불한다.
- [ ] 기존 옵션과 새 결과를 비교한 뒤 하나를 선택한다.
- [ ] 선택하지 않은 다른 슬롯, 어빌리티 레벨, 해금 슬롯 수를 유지한다.
- [ ] 다른 슬롯이 가진 옵션은 새 결과 후보에서 제외한다.
- [ ] 결과를 확정하기 전 다시 변경하거나, 재접속으로 비용 없이 재추첨하지 못하도록 후보와 결제 상태를 보관한다.
- [ ] 레벨별 변경 비용과 옵션 등장 확률을 데이터로 관리한다.

완료 기준: 변경 한 번에 골드가 한 번 차감되고 결과가 하나만 확정된다. 취소·종료 시 후보 처리와 비용 환급 여부는 구현 전에 결정한다.

어빌리티는 수치 옵션 시스템으로 구현한다. 앞서 예시로 제안한 추격·집중·역습 등 조건부 어빌리티는 이번 채택 목록에 넣지 않는다.

## 9. 몬스터·지역·외형

### CONTENT-01 · 기존 몬스터에 전투 역할 부여

- [ ] 같은 단계에서 모든 몬스터가 같은 체력·공격·주기를 사용하는 구조를 바꾼다.
- [ ] 우선 잡몹 무리·튼튼한 적·후방 원거리 적의 역할을 구현한다.
- [ ] 기존 슬라임·달팽이·버섯·유령·골렘을 활용하되 종류별 역할표를 확정한다.
- [ ] 보스를 단순 크기·수치 증가에서 고유 행동과 고유 보상으로 확장한다.

이전 역할 예시는 슬라임=무리, 달팽이=방어형, 버섯=후방 공격, 유령=전방 통과, 골렘=느린 강공격이다. 구체 패턴·공격 수치는 콘텐츠 설계 단계에서 확정한다.

### CONTENT-02 · 사냥터 선택과 파밍 목적

- [ ] 도달한 사냥터 선택과 자동 진행/반복 사냥 상태를 제공한다.
- [ ] 지역별 장비·재료 획득 목적을 만든다.
- [ ] 보스 실패 후 안정 사냥과 재도전 흐름을 정한다.
- [ ] 현재 사냥터와 최고 도달 단계, 최고 클리어 단계를 구분해 관리한다.

완료 기준: 높은 단계로 진행하는 목적과 특정 지역에서 반복 사냥하는 목적이 모두 존재한다. 지역별 획득처·보스 목록·재도전 자동화 조건은 미정이다.

### LOOK-01 · 외형 구매·해금·착용

- [ ] 성능 장비와 외형 선택을 분리한다.
- [ ] 초기에는 머리/모자·옷·무기 외형을 우선 지원한다. 장비 9슬롯과 외형 슬롯 수가 같아야 하는 것은 아니다.
- [ ] 골드 구매 외형을 영구 해금하고 자유롭게 교체한다.
- [ ] 무기 외형은 같은 종류끼리만 씌운다(예: 엽총에 검 외형 불가). 다른 종류를 허용할지는 미정이다.
- [ ] 캐릭터 렌더링을 외형 부위 조합에 대응하도록 바꾼다.
- [ ] 기본 구매 외형과 특별한 보스/수집 보상을 구분할 수 있도록 데이터 구조를 준비한다.

완료 기준: 외형 변경이 전투 능력치를 바꾸지 않고, 재실행 후 해금·착용 상태가 유지된다. 외형 상품·가격·보상 목록은 미정이다.

## 10. 화면과 조작

### UI-01 · 상주 띠와 관리 화면

- [ ] 작업 표시줄 위 480×110 투명 띠와 기존 일반 화면을 유지한다.
- [ ] 기존 강화 메뉴를 캐릭터 관리 진입 버튼으로 교체한다.
- [ ] 관리 화면에 능력치·스탯 투자·9슬롯 장비/인벤토리·장비 강화·어빌리티·외형을 제공한다.
- [ ] 장비/어빌리티 교체 전후 능력치와 현재 명중·치확·공속 상태를 보여준다.
- [ ] 관리 UI는 별도 창 또는 확장 패널을 사용한다. 둘 중 어느 방식인지는 Electron 창 코드 확인 후 선택한다.
- [ ] 평상시에는 다른 작업을 방해하지 않는다. 관리 화면을 사용하는 동안에는 입력 포커스를 유지할 수 있도록 기존 ‘클릭해도 맨 아래’ 규칙의 적용 범위를 나눈다.
- [ ] 별도 창을 쓰면 두 화면이 저장 파일에 독립적으로 덮어쓰지 않게 한다.
- [ ] Win+D 대응, 작업 표시줄 아이콘 숨김, 종료 방법, 배율별 선명도를 확인한다.
- [ ] 새 입력 규칙과 창 동작을 기존 MD에 반영한다.

완료 기준: 작은 띠에서 전투를 볼 수 있고, 관리 화면에서는 장비와 옵션을 읽고 조작할 수 있다. 관리 화면을 열고 닫아도 중복 전투나 보상이 발생하지 않는다.

## 11. 밸런스와 확인 목록

### BAL-01 · 성장·골드 경제

- [ ] 기본 능력치에서 레벨업 투자와 장비가 차지하는 비중을 정한다.
- [ ] 무기별 기본 공속을 먼저 맞추고 공속 어빌리티는 추가 성장으로 둔다.
- [ ] 강화·어빌리티 업그레이드·변경·외형 구매 비용을 실제 분당 골드 수입과 함께 조정한다.
- [ ] 외형 구매가 항상 전투 성장을 심하게 지연시키지 않도록 초기 가격을 조정한다.
- [ ] 평균 DPS만 보지 않고 분당 처치 수·골드·경험치, 보스 처치 시간, 사망 빈도로 조합을 비교한다.

### QA-01 · 통합 완료 확인

- [ ] 무기 3종이 단일 보스와 무리 전투에서 의도한 방식으로 동작한다. 상태 효과(경직·출혈·넉백·관통·폭발)가 정한 대로 걸리고 풀린다.
- [ ] 유니크 이상 무기 스킬이 정한 주기로 나가고, 피해·보상이 중복되지 않는다.
- [ ] 같은 적에게 한 공격의 피해·보상이 중복 적용되지 않는다.
- [ ] 장비·어빌리티·스탯 변경 결과와 실제 피해 계산이 일치한다.
- [ ] 잠금/장착 장비가 자동 분해되지 않는다.
- [ ] 반지 2슬롯, 외형 무기 종류 제한이 적용된다.
- [ ] 어빌리티 결과 선택 중 종료해도 비용·결과가 일관된다.
- [ ] 일반 진행·보스 실패·사망·재실행 후 사냥 모드가 정상 복원된다.
- [ ] 백그라운드·절전·재실행으로 방치 시간이 누락되거나 이중 지급되지 않는다.
- [ ] 기존 세이브 이전에 실패해도 원본이 남는다.
- [ ] 여러 적과 이펙트를 표시해도 바탕화면 상주에 맞는 부하와 가독성을 유지한다.

## 13. 이번 목록에 자동으로 포함하지 않는 것

**직업 시스템(전사·사수·암살자·마법사, 직업 선택·변경)은 v0.2에서 없앴다.** 암살자의 양손 단검도 무기 목록에서 빠졌다.

환생, 제작/거래, 펫, 멀티플레이, 길드, 일일 숙제, 스킬트리는 이번 대화에서 확정하지 않았다. 의뢰·도감은 이전 리뷰에서 제안했지만 독립 시스템의 범위가 정해지지 않아 별도 후속 작업으로 둔다. 예시 아이템과 예시 수치는 확정 데이터로 복사하지 않는다.

이번 문서 작성으로 게임 코드나 기존 MD가 변경되지는 않았다. 실제 구현 시 완료된 작업 ID와 남은 미정 항목을 함께 기록한다.
