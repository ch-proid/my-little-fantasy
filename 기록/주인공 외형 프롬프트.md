# 주인공 외형 프롬프트 (헤어·기본 옷·코스튬)

2026-09-30 작성. 주인공은 종이 인형이다(몸 → 하의 → 상의 → 헤어). 받은 그림에서 대머리 몸과 달라진 칸만 뽑아 파츠 PNG(18×28)로 만든다.

## 쓰는 법
1. GPT에 `레퍼런스/캐릭터/외형 프롬프트 첨부용_대머리와 기존 헤어.png`를 첨부한다. 왼쪽부터 대머리+기본 옷, 대머리 맨몸(기준 몸), 뾰족 머리, 긴 머리이다. (2026-09-30 새 몸으로 다시 만듦)
2. [공통]과 [묶음] 하나를 이어 붙여 넣는다.
3. 받은 그림은 `레퍼런스/캐릭터/외형_묶음이름.png`로 저장한다.

## 지켜야 하는 까닭 (프롬프트에 넣은 규칙)
- **얼굴·몸 틀 그대로**: 파츠를 겹치려면 눈·목·손·발 자리가 모든 그림에서 같아야 한다.
- **헤어는 크림 금발 4단계만**: 외형 상점의 머리색 바꾸기가 이 4색을 바꿔 칠한다.
- **기본 옷 셔츠는 크림 2단계, 바지는 갈색 2단계**: 옷색 바꾸기가 셔츠 색을 바꿔 칠한다.
- **다리 두 개가 보이게, 치마는 무릎 위까지**: 걷기 그림을 "다리 아래 5줄을 한쪽씩 들기"로 만든다.
- **코스튬은 모자·머리 장식 없이**: 헤어가 따로 얹힌다.
- **손은 비운다**: 무기를 쥘 자리다.

## [공통]
```
첨부한 그림은 도트 게임 주인공이다. 왼쪽부터 대머리에 기본 옷, 대머리 맨몸(기준 몸), 헤어 2종이다. 이 캐릭터를 바탕으로 아래 목록을 그린 도트 에셋 시트를 한 장으로 그려 줘.
- 모든 캐릭터는 첨부 그림과 똑같이: 같은 얼굴(눈 위치·크기), 같은 몸 크기와 자세, 같은 방향(몸이 살짝 왼쪽을 봄), 같은 손·발 위치. 도트 한 칸의 크기도 첨부 그림과 똑같이, 일정한 큰 네모 도트로.
- 실루엣은 원래 몸보다 사방 2칸 넘게 커지지 않게. 손에는 아무것도 들지 않는다. 두 다리가 따로 보이게 그린다.
- 모양은 단순하게: 큰 덩어리 몇 개, 굵고 어두운 테두리(첨부 그림과 같은 짙은 갈색), 색마다 명암 3단계 이내.
- 목록의 캐릭터를 가로 한 줄(많으면 두 줄)로, 서로 넉넉히 띄워 놓는다. 캐릭터 아래 글자는 넣지 않는다.
- 배경은 무늬 없는 한 가지 색(연회색 #d8d8d8). 그림자, 땅, 글자, 테두리 상자는 넣지 않는다.
```

## [묶음 1] 헤어 3종
```
목록: 첨부 그림의 대머리 캐릭터(기본 셔츠·바지 그대로)에게 새 헤어스타일 3종을 씌운 모습 3명.
- 머리색은 첨부 그림의 헤어와 똑같은 크림 금발 4단계(밝음·기본·그늘·깊은 그늘)만 쓴다. 다른 색을 섞지 않는다.
- 얼굴(눈·볼·귀)은 가리지 않는다. 앞머리는 눈썹 위까지. 머리칼은 어깨 아래로 내려오지 않는다.
1) 단발 보브: 턱선에서 가지런히 끊긴 둥근 단발, 옆으로 살짝 부푼 모양
2) 포니테일: 뒤통수 위에서 높게 묶어 뒤로 짧게 뻗은 꽁지머리, 앞머리는 옆으로 넘김
3) 짧은 곱슬머리: 동글동글 뭉친 곱슬이 머리 위에 소복하게 얹힌 모양
```

## [묶음 2] 기본 옷 3종
```
목록: 첨부 그림의 대머리 캐릭터에게 새 기본 옷 3벌을 입힌 모습 3명 (헤어 없이 대머리 그대로).
- 모두 평범한 모험가의 기본 옷이다. 모양만 다르게 하고 색은 맞춘다: 윗옷은 첨부 그림 셔츠와 같은 크림색 2단계, 아래옷은 첨부 그림 바지와 같은 갈색 2단계, 신발은 첨부 그림과 같은 짙은 갈색 장화.
- 드러나는 팔 살은 첨부 그림의 손과 같은 살색.
1) 나시와 반바지: 어깨가 드러나는 민소매 윗옷, 무릎 위 반바지
2) 긴팔티와 긴바지: 손목까지 오는 긴 소매 윗옷, 발목까지 오는 바지
3) 조끼 셔츠와 멜빵바지: 반팔 셔츠 위에 짧은 조끼, 멜빵이 달린 바지
```

## [묶음 3] 코스튬 10종 (한 벌 옷)
```
목록: 첨부 그림의 대머리 캐릭터에게 예쁘고 화려한 한 벌 코스튬 10종을 입힌 모습 10명 (헤어 없이 대머리 그대로, 5명씩 두 줄).
- 코스튬마다 색 5~7가지로 또렷하게, 금·은 장식이나 반짝이는 포인트를 한두 곳 넣는다.
- 모자, 머리띠, 가면 등 머리에 쓰는 것은 넣지 않는다. 망토·옷자락은 허리 아래까지만, 치마는 무릎 위까지.
1) 벚꽃 무희: 분홍 벚꽃 무늬의 소매 넓은 한 벌 옷, 허리에 금색 끈
2) 별빛 마법사: 남색 짧은 로브에 금색 별자리 자수, 어깨에 작은 케이프
3) 해적 선장: 빨간 긴 코트(허리까지)와 금단추, 흰 셔츠, 검은 바지와 장화
4) 왕실 기사: 흰색과 금색의 기사 제복, 가슴에 파란 문장, 짧은 파란 망토
5) 겨울 축제: 빨간 털 코트에 흰 털 테두리, 초록 목도리
6) 꽃 요정 정원사: 연두 잎사귀 튜닉에 꽃잎 옷자락, 허리에 작은 꽃 장식
7) 태양의 순례자: 흰 천 옷에 금 띠와 청록 보석 장식, 헐렁한 바지
8) 그림자 닌자: 검은색과 짙은 보라의 닌자 옷, 허리에 보라 띠
9) 궁정 음유시인: 노랑과 자주 두 가지 색으로 반씩 나뉜 화려한 옷, 금 단추
10) 용기사 예복: 붉은 비늘 무늬 조끼와 금 테두리, 검은 바지와 붉은 장화
```

## 받은 뒤 할 일

- 기본 옷: 목 아래를 뽑아 허리선에서 나눠 `상의_이름.png`, `하의_이름.png`로 만든다.
- 코스튬: 목 아래 전체를 한 파츠로 만든다. 새 종류 "코스튬"이 필요하다. 입으면 상의·하의 대신 겹치고, 외형 탭에서 입고 벗는 기능을 게임에 더한다.
